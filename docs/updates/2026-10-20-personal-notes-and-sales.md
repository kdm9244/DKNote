# 메모·매도·학습 자료 개선

- 사이드바의 마이를 메모(`/notes`)로 교체. 계정 정보는 하단 사용자 카드로 접근합니다.
- 독립 MEMO 문서에 제목·본문·고정 여부를 계정별 서버 저장합니다. 수정 버전 충돌을 거절하며 미저장 초안은 사용자·메모별 브라우저 저장소에 보관합니다.
- 전량 매도한 0주 종목은 보유 표에서 숨깁니다. 종목과 거래 기록은 보존하므로 재매수·과거 손익 계산은 유지합니다.
- 학습 상세의 PDF 업로드 링크에서 현재 목표 ID를 전달합니다. 업로드 전 연결 대상을 변경할 수 있습니다.
- 매도 거래세는 계좌의 수동 sellTaxRate 대신 서버 법정 기본값을 사용합니다. 거래별 실제 세액·수수료 입력은 자동값보다 우선하며 0을 입력하면 면제·무료 이벤트를 반영합니다. 기존 저장 거래는 재계산하지 않습니다.

## 자동 세금 범위

- 한국 KOSPI/KOSDAQ/KRX 장내 일반 주식: 2025년 합계 0.15%, 2026년 합계 0.20%. KOSPI 농어촌특별세 포함. KONEX 0.10%.
- 국내 INDEX_ETF는 투자신탁형 ETF로 가정해 거래세 0. 배당주/ETF 혼합 분류, 불명확한 시장, 지원 기간 밖 일반주식은 실제 세액 입력을 요구합니다.
- 일본 거주자의 JPY 종목은 매도금액에서 수수료·등록 평균 취득가를 뺀 양의 차익에 대해 20.315% 참고 소득세를 표시합니다. NISA는 0. 해외 통화는 기존 연간 정산의 환산을 사용합니다.
- 일본의 참고 소득세는 실제 원천징수액으로 간주하지 않으며 예수금에서 자동 차감하지 않습니다. 연간 손익통산·환급·증권사 계산과 다를 수 있으므로 실제 차감액은 정산서 기준으로 기록합니다. 미국 시장의 부과금 및 국내 ETF 소득세 등은 이 거래세 규칙의 자동 계산 범위가 아닙니다.
- 세액은 통화 단위 미만을 버린 참고액이며 실제 정산액으로 수정할 수 있습니다. 확정 신고·납부를 자동 처리하지 않습니다.

## 반영

운영 prod 프로필은 시작 시 Flyway V8로 MEMO 허용 제약을 확장합니다. Flyway가 꺼진 기존 개발 DB에는 `src/main/resources/db/migration/V8__personal_memos.sql`을 적용해야 합니다. 기존 테이블·기록은 삭제하지 않습니다. 새 프런트엔드 빌드와 서버 재시작이 필요합니다.
