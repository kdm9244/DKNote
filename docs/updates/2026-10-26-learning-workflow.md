# 2026-10-26 학습·PDF·일정 사용성 업데이트

## 1. 페이지 이름과 아이콘
- 브라우저 탭의 `frontend`를 `DKNote · 나의 학습과 일정`으로 변경했습니다.
- Vite 기본 아이콘을 보라색 노트 아이콘으로 변경했습니다.
- 페이지 기본 언어를 한국어로 지정했습니다.

## 2. PDF 분류 변경
- 하단에 있던 자료 정보·분류 변경·다운로드를 PDF 상단으로 옮겼습니다.
- 접힌 상태에서도 현재 로드맵 / 세부 목표 / 학습 할 일 경로를 확인합니다.
- 로드맵 → 세부 목표 → 학습 할 일의 단계별 선택과 경로 검색을 제공합니다.
- 중간 단계에 연결하거나 독립 자료로 변경할 수 있습니다. 변경 후 ‘자료 정보 저장’을 누르세요.

## 3. 간결해진 에디터
- 본문 줄 높이를 1.85에서 1.6으로, 문단 아래 여백을 0.7em에서 0.25em으로 줄였습니다.
- 글자색·형광펜 등 텍스트 서식을 ‘서식 더보기’ 안에 모았습니다.
- 드래그한 글자 가까이에 서식 도구가 나타나며, 기존 표·목록·코드 기능도 유지합니다.

## 4. 필기 제목
- 글자를 드래그한 뒤 ‘선택한 문단 제목’에서 본문 / 큰 제목 / 중간 제목 / 작은 제목으로 바꿀 수 있습니다.
- 학습노트 코드 영역의 줄 번호로 선택한 설명에 ‘필기 제목’을 입력할 수 있습니다.
- 기존 설명도 제목과 내용을 함께 수정할 수 있습니다. 제목을 비우면 기본 제목을 사용합니다.

## 5. Markdown 전환
- 문서 편집에서 Markdown으로 돌아가는 버튼을 사용할 수 있습니다.
- 기본 문단·제목·강조·목록·인용·코드를 Markdown으로 변환합니다.
- Markdown에서 문서 편집으로 전환한 뒤 내용을 수정하지 않았다면 원본 Markdown을 복원합니다(같은 편집 화면 내).
- 표·밑줄·글자색·형광펜이 포함된 문서는 내용을 유지하고 ‘Markdown으로 돌아가실 수 없습니다’ 경고와 이유를 표시합니다.
- 모든 문서 서식을 Markdown으로 완전히 변환하는 기능은 아닙니다.

## 6. 일정에 여러 자료 연결
- 일반 일정에서 ‘연결된 자료 → 자료 연결·해제’를 열어 학습노트·PDF·일반 메모를 여러 개 선택합니다.
- 제목으로 검색할 수 있고, 연결된 자료를 눌러 해당 자료를 엽니다.
- 일반 일정은 일정 저장 시 반영하며, 학습 예정일·목표 기간의 연결 변경은 자동 저장합니다.
- 연결은 기존 자료의 학습 목표 분류를 바꾸지 않습니다. 연결 해제는 자료 삭제가 아닙니다.
- Google 일정의 연결 정보는 기존 로컬 보조 데이터와 함께 보관합니다.

## 검증 범위
- 프런트엔드 프로덕션 빌드, lint, 미사용 모듈 검사.
- 모의 API 기반 브라우저 회귀 테스트: 실제 사용자 데이터는 변경하지 않습니다.
- 실서비스 배포와 실제 Google 계정 연동 검증은 포함하지 않습니다.

- `npm run lint`: 오류 없음(기존 React Hook 의존성 경고 8건 유지).
- `npm run check:unused`: 통과, 미사용 모듈 없음.
- `learning-workflow-update.mjs`: 통과. Markdown 변환·편집·저장, 원본 복원, 서식 경고, 드래그 제목 서식, 설명 제목, 일정 자료 다중 연결 및 재조회, 학습 예정일 자동 저장, 메모 바로 열기, PDF 상단 분류 변경과 모바일 너비 확인.
- `learning-notes-improvements.mjs`: 통과. 공백·빈 문단 보존, 저장·재편집, 드래그 서식, 목표 검색·계층 연결, 목록·필터, 데스크톱·모바일 회귀 확인.
- `pdf-view-ui.mjs`: 통과. PDF·필기·단어 보기 전환, 뷰어 유지, 페이지 이동, 숨긴 필기의 자동 저장, 초안과 분할 비율, 노트북·모바일 회귀 확인. 테스트의 이전 저장 문구·페이지 입력 이름을 현재 UI에 맞추고 학습 보기 전환을 명시했습니다.

## 추가 재점검 및 보완

사용자가 이용하는 흐름과 저장 실패 상황까지 재점검해 다음 사항을 보완했습니다.

- **Markdown 내용 보호 강화:** 들여쓴 글이 코드로 바뀌거나, 빈 문단·마지막 줄바꿈이 사라지는 전환을 차단합니다. 코드 끝의 줄바꿈도 유지하도록 보완했습니다. 변환한 결과를 다시 읽어 원문의 구조와 비교하고, 그대로 보존할 수 없으면 원문을 유지하고 안내합니다.
- **필기 설명 표시 수정:** 문서 편집으로 작성한 코드에 설명을 붙였을 때 실제로 바뀌지 않은 코드를 ‘변경됨’으로 표시할 수 있던 검사를 수정했습니다. 일반 댓글을 수정할 때 존재하지 않는 선택 줄 범위가 표시되지 않게 했습니다.
- **메모 이동 개선:** 다른 메모를 선택하면 주소도 함께 바뀝니다. 새로고침이나 브라우저 뒤로가기를 해도 주소에 맞는 메모가 열립니다.
- **저장 과정 보호:** 학습노트와 설명을 저장하는 동안 추가 입력·서식 전환으로 내용이 뒤섞이지 않게 했습니다. 자료 연결 저장에 실패하면 기존 연결을 유지하며 다시 시도할 수 있도록 안내합니다. 빠른 중복 저장도 방지합니다.
- **모바일 서식 메뉴:** ‘서식 더보기’를 펼쳤을 때 도구가 화면 안에 표시되도록 정리했습니다. 자료 검색 결과가 없을 때도 안내합니다.

### 재점검 결과

- `markdown-conversion-safety.mjs`: 통과. 들여쓰기·빈 문단·마지막 줄바꿈·인라인 코드 등 손실이 발생할 수 있는 전환 보호, 제목·중첩 목록·인용·코드 변환 확인.
- `learning-workflow-update.mjs`: 통과. 기존 기능 외에 저장 중 입력 보호, 변경되지 않은 코드 설명 표시, 일반 댓글 편집, 자료 검색 빈 결과, 자동 연결 저장 실패 후 재시도, 메모 선택·새로고침·뒤로가기, 모바일 서식 메뉴 확인.
- `learning-notes-improvements.mjs`, `pdf-view-ui.mjs`: 모두 통과.
- 프로덕션 빌드·lint·미사용 모듈 검사·diff 공백 검사: 모두 통과. 기존 Hook 의존성 경고와 번들 크기 안내는 유지됩니다.
- 실제 사용자 데이터와 Google 계정에는 변경을 가하지 않았으며, 실서비스 배포는 포함하지 않았습니다.

## 새 노트에 이전 내용이 다시 나타나는 문제 수정

- **원인:** 같은 목표에 새 노트를 작성할 때 임시 저장 위치를 공유했고, 저장 중 편집 잠금을 변경하는 동작도 내용 변경으로 처리되어 저장한 초안이 다시 남을 수 있었습니다.
- **변경:** ‘노트 작성’을 누를 때마다 독립된 새 초안을 만들고 빈 화면으로 시작합니다. 같은 목표에 여러 노트를 각각 작성·저장할 수 있습니다.
- **기존 초안:** 삭제하지 않습니다. 새 노트 화면의 ‘작성 중인 노트 → 이어서 작성’에서 선택해 복구할 수 있습니다. 이전 방식으로 보관된 초안도 이어쓰기와 저장을 지원합니다.
- **새로고침:** 현재 작성 중인 노트의 초안은 그대로 복원합니다. 다시 ‘노트 작성’을 누르면 별도의 빈 노트가 열립니다.
- **검증:** 같은 목표의 두 노트를 서로 다른 ID로 저장하고 두 본문이 독립적으로 유지되는지, 초안 선택·새로고침·저장 실패 후 재시도·기존 초안 복구·빈 초안 정리를 확인했습니다.
- `learning-multiple-notes.mjs`, `learning-note-ui.mjs`, `learning-notes-improvements.mjs`, `learning-workflow-update.mjs`, `pdf-view-ui.mjs`: 모두 통과. 빌드·lint·미사용 모듈 검사·diff 공백 검사 통과(기존 경고 유지).
- 로컬 프로젝트에 반영했으며 실서비스 배포는 포함하지 않았습니다.
