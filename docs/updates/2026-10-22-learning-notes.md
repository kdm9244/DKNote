# 2026-10-22 학습노트 개선

## 작성 내용 보존

- 문서 편집·미리보기·상세 화면의 공백과 문단 표시 규칙을 맞췄습니다.
- 연속 공백, 들여쓰기, 줄바꿈, 빈 문단을 저장·새로고침·재편집할 때 유지합니다.
- 문장 끝의 줄바꿈과 코드 블록 끝의 빈 줄도 표시합니다.
- Markdown의 일반 줄바꿈을 화면에 표시하고, 문서 편집으로 변환할 때도 유지합니다.

## 연결할 목표 검색과 계층 선택

- 목표 이름과 전체 경로로 연결 항목을 검색합니다. 같은 이름의 목표도 상위 경로로 구분합니다.
- 로드맵 → 세부 목표 → 학습 할 일 순서로 선택 범위를 좁힙니다.
- 로드맵이나 세부 목표에 바로 연결하거나 독립 노트로 작성할 수 있습니다.
- 편집 화면에서는 현재 연결 경로를 먼저 보여주고, 변경할 때 검색·선택 도구를 펼칩니다.
- 검색 결과가 많으면 총 개수와 앞 40개를 표시하고 검색어를 좁히도록 안내합니다.

## 편집 도구

- 도구 모음을 문서 구조, 텍스트 서식, 목록·삽입 기능으로 정리했습니다.
- 제목 단계, 기울임, 밑줄, 번호 목록, 인용 도구를 제공합니다.
- 글자를 드래그하면 선택 영역 가까이에 굵게·기울임·밑줄·글자색·형광펜·서식 해제 도구가 나타납니다.
- 현재 적용된 서식과 저장 후 다시 불러온 색상을 도구 모음에 표시합니다.

## 학습 기록 목록과 상세 화면

- 학습노트·PDF를 종류, 제목, 본문 미리보기, 연결 경로, 공부 날짜 중심의 간결한 목록으로 표시합니다.
- 자료 종류 탭, 검색, 정렬을 앞에 두고 계층 분류·날짜·형식 필터는 필요할 때 펼칩니다.
- 독립 자료 필터와 필터 초기화를 추가했습니다. 목록은 한 페이지에 최대 10개를 표시합니다.
- 목표 상세의 연결된 학습 기록을 기본으로 펼치고 계획 영역과 구분했습니다.
- 노트 상세에는 각 목표로 이동할 수 있는 연결 경로를 표시합니다.
- 본문 아래 댓글 영역을 접을 수 있으며, 코드 줄을 선택하면 자동으로 펼칩니다.
- 모바일에서 목록과 편집 화면이 화면 너비에 맞도록 조정했습니다.

## 검증

- `npm run build`, `npm run lint`, `npm run check:unused` 통과. 기존 정적 검사 경고와 번들 크기 경고는 남아 있습니다.
- `node tests/learning-notes-improvements.mjs`: 실제 입력·미리보기·저장·새로고침·재편집, 공백·빈 문단·코드 마지막 줄, 드래그 서식, 동명 목표 검색·계층 선택, 분류·페이지 이동, 모바일 화면 검증.
- `node tests/learning-note-ui.mjs`: 작성·편집, 초안 복구, 저장 실패, 단축키와 필수 입력, 상위 목표·날짜 연결 검증.
- `node tests/learning-compact-ui.mjs`: 표 편집, 로드맵과 연결 자료, 모바일 배치 등 회귀 검증.
- `node tests/personal-notes-learning-ui.mjs`: 메모와 PDF 연결·업로드 흐름 회귀 검증.
- 브라우저 검증은 API를 모의 응답으로 대체하여 실제 DB를 변경하지 않았습니다.
