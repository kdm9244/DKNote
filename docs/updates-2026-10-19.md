# 2026-10-19 업데이트 검토

현재 작업 폴더에 반영했으며, 운영 웹에는 배포하지 않았습니다. 후속 요청으로 연결된 로컬 DB에 `kdeok` 공지 등록 전용 계정을 생성했습니다. 비밀번호는 BCrypt로만 저장하고 저장된 해시 일치까지 확인했습니다. 운영 환경의 계정은 별도 생성 대상입니다.

## 반영 내용

- PDF: 현재 뷰어에 PDF.js 텍스트 레이어를 추가해 글자 드래그 선택과 복사를 지원합니다. 확대·페이지 이동을 유지하며, 텍스트가 없는 스캔 PDF에 OCR을 추가하지는 않았습니다.
- 체크리스트: 일정 상세와 오늘 일정/일정 목록에서 바로 제목 수정·삭제. 저장 실패 시 입력을 유지하고 재시도합니다.
- 학습노트 표: 생성 행·열 수 선택, 행·열 추가와 삭제, 전체 표 삭제, 열 너비의 안전한 저장. 행·열 도구는 표 안을 선택한 뒤 펼칩니다.
- 학습 자료: 학습노트와 PDF를 같은 목록에서 검색·필터링합니다. PDF 원본, 페이지 필기와 기존 URL은 보존합니다.
- 단어장: 편집 버튼과 편집창을 해당 단어 옆/아래에 배치하고 맨 아래의 중복 편집 버튼을 제거했습니다. PDF 단어 편집 표는 모바일에서 카드로 표시합니다.
- 통장 통화: 계좌 유형을 바꿔도 선택한 통화를 유지합니다. 엔화 통장의 차액이 0일 때 원화로 표시되던 오류를 수정했습니다.
- 투자 비용: 요율 설정 외에 등록된 매수·매도·배당의 수수료, 세금, 세금 구분, 메모를 수정합니다. 비용 차액은 현재 예수금에 반영하고, 과거 매수 비용을 수정하면 전체 거래기록을 검증한 뒤 이후 매도 실현손익과 남은 이동평균 원가를 재계산합니다. 수량·단가·일자 변경은 이번 비용 수정에 포함하지 않습니다. 거래 버전과 계좌 잠금으로 중복/동시 수정에 대응합니다.
- 연간 투자 정리: 일반계좌 / 특정계좌(원천징수 있음·없음) / NISA / 미설정 중 선택합니다. 기존 계좌는 미설정입니다. 연도별 전체 거래를 집계하고 통화별 매수·매도·배당·수수료 및 거래세/원천징수/기타/미분류 세금을 표시합니다. 세전·세후 실현손익은 계좌 통화로 표시하며 전체 내역 CSV를 내려받습니다. 일본 매도세금은 매도대금에 세율을 곱하지 않고 실제 세액을 입력합니다.
- 공지: 로그인 화면 옆의 불투명한 흰색 패널에서 로그인 없이 최근 5개 소식을 읽습니다. 모바일에서는 로그인 폼 아래에 표시합니다. `/updates` 작성 화면은 제목·버전·내용 입력과 목록 넣기, 실시간 미리보기를 제공합니다. ADMIN은 등록·수정·삭제가 가능하고, NOTICE_PUBLISHER는 조회·등록만 가능합니다. `kdeok`은 후자이며 개인 자료/가계부 API 및 공지 수정·삭제가 차단됩니다. 공개 API는 공지 표시용 필드만 반환하며 비밀번호나 기본 관리자 자격 증명은 소스에 저장하지 않습니다.
- 모바일: 표 도구 접기, 저장 도구의 고정 메뉴 겹침 방지, 체크리스트 버튼/입력 크기, 단어장 여백과 편집 배치를 조정했습니다.

## 검증

- 프런트엔드 프로덕션 빌드.
- `frontend/tests/updates-ui.mjs`: 빌드 결과를 사용하고 모든 API를 모킹. 표 구조 변경/너비 저장/삭제/실행 취소, 자료 통합/필터, 단어 수정, 체크 항목 수정/삭제/저장 실패 복구, 일정 편집창 위치, 공지 CRUD/관리자 UI/저장 실패, JPY 통장 생성/표시/유형 변경, 수수료·세금 별도 표시와 요율 변경. 360/390/768px 화면 너비의 가로 넘침 검사.
- `frontend/tests/pdf-selection-ui.mjs`: 마우스 선택, 확대 후 선택, 페이지 전환, 모바일 텍스트 레이어.
- Maven 대상 테스트 16개: `RichTextSanitizerTest`, `ReleaseNoticeServiceTest`, `AccountServiceTest`.
- 후속 변경 대상 Maven 테스트 22개: `InvestmentCostCorrectionTest`(14), `PublisherLoginTest`(2), `NoticePublisherFilterTest`(2), `ReleaseNoticeServiceTest`(4). 비용 수정/중복 호출/원가 기록 불일치/잔액 부족/다른 계좌 차단/버전 충돌/전량 매도/일본 세액 입력/연간 세금 구분을 검증합니다.
- `frontend/tests/investment-corrections-ui.mjs`: 비용 수정 실패와 재시도, 버전 전달, 연간 집계 갱신, 연도·과세 유형 선택과 저장 실패, 65건 전체 CSV/수식 주입 방지, 모바일 360/390/768px, 공지 전용 계정의 페이지 이동/공지 등록 및 불필요한 개인 API 요청 차단을 확인했습니다.
- 공지 화면 후속 검증: `frontend/tests/notices-ui.mjs`에서 로그인 옆 불투명 패널, 긴 공지 스크롤·이전 소식 이동, 조회 실패 재시도, 작성 미리보기·목록 넣기·저장 실패 복구, 360/390/768px 배치를 확인했습니다. `ReleaseNoticeServiceTest`와 `NoticePublisherFilterTest` 7개 대상 테스트도 통과했습니다.
- 로컬 서버에서 실제 공지 조회, 비로그인 쓰기 차단, 등록 전용 계정의 미리보기·개인 API 차단까지 확인했습니다. `/updates` 직접 접속·새로고침 시 404가 나던 SPA 연결을 추가하고 재확인했습니다. 이 검증에서는 공지 내용을 저장하거나 변경하지 않았습니다.
- 실제 운영 데이터와 공지는 변경하지 않았습니다. 실제 휴대폰의 키보드/터치 동작은 사용자 확인이 필요합니다.

## 학습 화면 UI/UX 후속 반영

- 표 생성은 8×8 격자 선택창과 키보드 방향키로 크기를 선택하고 바로 삽입합니다. 더 큰 표는 직접 입력할 수 있으며 첫 행 제목 여부도 선택합니다. 행·열 편집 역시 본문을 밀지 않는 메뉴로 표시합니다.
- 학습노트 저장 헤더, 필기 제목과 글쓰기 서식 도구의 스크롤 고정을 해제했습니다. 편집기 초기 렌더링 중 이미 해제된 인스턴스를 참조하던 오류도 수정했습니다.
- 단어장은 암기·표기·읽는 법·뜻·편집 순서의 목록으로 바꾸고, 한 페이지만 있으면 페이지 이동을 숨깁니다. 암기 처리 후 행 위치를 유지하고 모바일 필터는 펼쳐 사용합니다.
- 로드맵은 제목·기간·진행률·다음 할 일의 요약 목록으로 표시합니다. 상세에서는 세부 목표별로 할 일을 펼쳐 완료 처리하며, 학습 예정일과 연결 자료는 접어 둡니다. 편집·순서 이동은 행 메뉴에서 사용할 수 있습니다.
- PDF는 원본 보기를 기본으로 학습 보기와 전환할 수 있으며 보기 선택을 브라우저에 기억합니다. 원본에서는 필기 페이지를 직접 맞춥니다. 학습 보기에서는 글자 선택과 화면 이동을 분리하고 선택 모드에서 터치 이벤트를 가로채지 않습니다. 텍스트가 없거나 텍스트 레이어가 실패하면 안내합니다.
- 모바일 로그인 화면은 최신 공지 안내만 표시하고 `/news`의 공개 공지 페이지로 이동합니다. 돌아오면 로그인 입력이 유지되며 로그인 비밀번호는 브라우저 저장소에 저장하지 않습니다. PC 공지 패널은 유지합니다.
- `learning-compact-ui.mjs`: 격자 크기·키보드·표 저장, 도구 고정 해제, 단어 암기/편집 실패 복구/검색, 로드맵 목표 펼치기/완료/연결 자료, 모바일 공지 이동·조회 실패 재시도·로그인 입력 복귀, 360/390/768px 배치를 모의 API로 검증했습니다.
- `pdf-selection-ui.mjs`: 원본/학습 전환, 필기 페이지 유지, 보기 기억, 영문/일본어 선택과 CMap 로딩, 텍스트 없는 페이지 안내, 확대/페이지 이동/모바일 배치를 검증했습니다. `notices-ui.mjs`의 기존 공지 작성·미리보기·실패 복구 검증도 통과했습니다.
- 사용자 실제 PDF의 글자 선택과 실제 휴대폰의 길게 누르기·확대 동작은 사용 환경에서 추가 확인이 필요합니다.
- PDF 상단 후속 정리: 보기 전환·페이지·확대·선택/이동·새 창을 한 줄 도구로 모으고, 원본 보기 설명·일반 조작 설명·중복 자동 저장 안내·PDF 필기의 단축키 설명을 제거했습니다. 중복 페이지 제목을 숨기고 자료 경로와 화면 보기 버튼도 한 줄로 정리했습니다. 오류/텍스트 없음 상태는 유지합니다.
- 한 줄 도구의 높이, PDF가 도구 바로 아래에서 시작하는 배치, 360/390/768px 가로 넘침과 모바일 도구줄 스크롤 접근, 보기 전환·필기 유지·글자 선택을 `pdf-selection-ui.mjs`로 재확인했습니다.

## 남은 결정

1. 배포 환경에 V2~V4 스키마 변경을 적용하고 새 코드로 배포해야 웹에서 새 로그인/투자 기능을 사용할 수 있습니다. 로컬 DB는 공지 전용 계정을 만들기 위한 V3만 적용했습니다. Flyway를 쓰지 않는 로컬 프로필은 JPA 기본값도 정의되어 있습니다.
2. 각 투자 계좌의 실제 과세 유형을 선택하고 증권사 연간거래보고서와 입력 내역을 대조해야 합니다. 기존 세금은 임의로 분류하지 않고 미분류로 보존합니다. 연간 화면은 입력 기록 집계이며 누락 거래, 추가 납부/환급, 신고에 필요한 법정 원가·환산 방식 등을 자동 보완하지 않습니다.
3. 모바일 배치와 학습노트·PDF 통합 목록의 사용감. 전체 색상/브랜드를 바꾸는 전면 디자인 개편은 아직 하지 않았습니다.
